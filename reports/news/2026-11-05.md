<b>1. Post: Security wake-up — the update path is the attack surface</b>
Three firmware-update bugs this year share one pattern: the updater trusted too much.

A Zephyr LwM2M flaw (CVE-2026-10672) leaks memory through crafted CoAP requests, a Caliptra runtime bug (CVE-2026-5818) bypasses update authentication, and CVE-2026-54799 flags a faulty signature check.

The engineering point: OTA code parses attacker-influenced input before any signature is checked. The parser is attack surface, not just the verifier.

Which part of your OTA path runs before authentication?

Espressif's ESP32-S31 puts Gigabit Ethernet next to a low-power core.

<b>4. Post: Physics-meets-architecture — 800 MHz on 18nm FD-SOI</b>
ST's STM32V8 runs a Cortex-M85 at up to 800 MHz, and the process matters as much as the core.

It is built on 18nm FD-SOI, which is where the clock speed headroom for a microcontroller comes from.

For firmware, that means cache and memory-latency behaviour start to look like application-class design.
