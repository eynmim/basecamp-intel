<b>1. Post: Security wake-up — the verifier is the target</b>
Six bugs in the code that checks your firmware signature.

Binarly reported six flaws in U-Boot's FIT signature verification, two of them RCEs that bypass Secure Boot, across more than 50 firmware releases.

What stays with me: the signature check is itself parsing untrusted data before it can say yes or no. A strong key does not help if the parser is bypassable. And devices from vendors that stopped supporting older models may never get the fix.

When did you last audit the bootloader, not just the application?

An MCU with a neural accelerator for under $1.

<b>3. Post: Integration leap — RISC-V vectors meet Arm cores</b>
Cortex-M85, Cortex-M52, and a RISC-V vector NPU on one chip.

Synaptics' Astra SR200 combines Arm Cortex-M85 and M52 cores with an NPU built on second-generation Coral IP, which includes RISC-V vector core support.

Mixed ISAs on one die used to be an oddity. Here the accelerator is RISC-V while the control cores stay Arm, so toolchains and firmware split across two worlds.

Matter is learning to onboard devices without a Bluetooth radio.
