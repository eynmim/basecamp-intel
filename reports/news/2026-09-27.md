<b>═ 🔥 TOP STORY ═</b>
Security researchers publicly disclosed a batch of at least fourteen CVEs (CVE-2026-80143 through CVE-2026-80156) in Lantronix's Autonomous Out-of-Band console-management appliances — the SLC8000, EMG7500/EMG8500, and SLB882/SLCx-02/SLCx-03 lines — the boxes network and data-center engineers wire directly into a router's or server's serial console port specifically so they can still reach it when the primary network is down. The worst, CVE-2026-80155 (CVSS 10.0), is an unauthenticated auth bypass: the web management portal builds its session-cookie file path with a fixed-size snprintf buffer, and a cookie value of the right length truncates that path so the session check validates against an arbitrary on-disk file instead — including the local user database — handing an attacker a working session with zero credentials. Other bugs in the same batch add OS command injection via undocumented factory-service commands, a stack buffer overflow (CVSS 9.9), and SSRF in the WebSSH/WebTelnet listener, so a single unpatched box can be walked from "no password" to root and then out to whatever serial-connected gear it was installed to protect. Firmware fixes exist per-device (SLC8000 before v9.7.0.5, EMG before v9.7.0.1) but the SLB882/SLCx-02/03 line has no patched firmware at all yet. Why it matters: an out-of-band management appliance is the device teams install as their break-glass fallback — when the thing meant to save you during an outage is itself the unauthenticated way in, the entire "OOB access is inherently more trusted" assumption behind most network architectures needs a second look.

<b>1. Post: Security wake-up — the break-glass box that needed no password</b>
An out-of-band console manager exists for one job: let you back into your network when everything else is down. Fourteen new CVEs just showed that same box can let anyone else in too.

Researchers disclosed CVE-2026-80143 through CVE-2026-80156 in Lantronix's SLC8000, EMG, and SLB882 console-server lines. The worst, CVE-2026-80155 (CVSS 10.0), is an unauthenticated auth bypass: the web portal builds its session-cookie file path with a fixed-size snprintf buffer, and a cookie of the right length truncates that path so the session check validates against an arbitrary file on disk — including the local user database.

The insight that matters here isn't the bug class, it's the target. Out-of-band management gear is trusted by design, precisely because it's the fallback path when the primary network fails. A vulnerability there doesn't just compromise one device — it compromises the safety net.

If your infrastructure has an OOB console server, do you know which firmware version it's running right now?

<b>2. Post: Regulatory shift — the CRA's fine print is being written in public, right now</b>
The Cyber Resilience Act's compliance baseline isn't finished. It's in public review, and the comment window closes on a rolling basis between now and mid-November.

Seventeen ETSI "vertical" draft standards are in Public Enquiry — these are the technical annexes that will eventually let a manufacturer claim Article 27's presumption of conformity. As of mid-August, zero CRA harmonised standards had been published in the Official Journal, so right now no product category can claim that presumption at all.

Most engineers will only meet these standards once they're finalized, mandatory, and enforced by a compliance team handing down a checklist. Reading the drafts now, while they're still open for comment, is the difference between learning the rules after they're set and understanding why they were written that way.

Would knowing the draft annexes before they're final change how you'd architect a device's security today?

<b>3. Post: Integration leap — turning "for each device" into "for all devices, once"</b>
Controlling five smart lights used to mean sending five separate commands. Matter just made that officially one.

Matter 1.6.1 takes Groupcast out of provisional status, making it the recommended way to address multiple devices: a single IPv6 multicast message instead of a sequence of individual unicast commands. It also adds volume and mute controls for doorbell chimes — a small fix for an annoyingly common complaint.

The multicast-over-unicast shift sounds minor until you've built the naive version yourself: sequential unicast means visible per-device lag and a control plane that scales linearly with device count. Groupcast collapses that into one packet, one network hop, and (in principle) simultaneous execution across every recipient.

If you're building a Matter-over-Thread project, would you architect group control differently knowing Groupcast is now the recommended path rather than a provisional afterthought?

<b>4. Post: Capability unlock — 150 million devices in, LoRaWAN stopped needing an argument</b>
150,000,000. That's how many LoRaWAN devices are now deployed worldwide, per the LoRa Alliance's latest count.

The Alliance also reports 340+ member organizations — 45 of them new this year — and roughly 695 certified device types, spanning close to 1,000 marketplace products. And the framing has shifted: LoRaWAN is increasingly deployed alongside cellular, Wi-Fi, BLE, and satellite per-device, not pitched as a standalone alternative to any of them.

That scale changes an engineering decision that used to require a leap of faith. At 150 million devices and hundreds of certified product lines, mixing and matching vendors on a LoRaWAN deployment is no longer a bet on an emerging ecosystem — it's picking parts off a shelf.

<b>5. Post: Price-floor shift — pre-certified silicon deletes a line item from your schedule</b>
Radio compliance testing can add months to a product launch. Quectel just shipped a module that lets you skip that step entirely.

The FGH200M, built on Morse Micro's MM8108 SoC, is now FCC/IC/CE/RCM certified at the module level for long-range, sub-1GHz Wi-Fi HaLow connectivity. Morse Micro says that certification work otherwise adds months to a development schedule — OEMs integrating the pre-certified module inherit that compliance instead of repeating it.

This is the quiet, unglamorous version of a price-floor shift: not a cheaper chip, but a cheaper path to market. For long-range IoT designs that would've defaulted to LoRaWAN partly to dodge Wi-Fi's certification overhead, that calculus just moved.
