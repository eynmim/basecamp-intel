<b>1. Post: Regulatory shift — Reporting clock is already running</b>
Since 11 September, a 24-hour clock applies to some firmware bugs in the EU.

The Cyber Resilience Act's reporting duties are live: actively exploited vulnerabilities need an early warning within 24 hours and a full notification within 72. The rest of the Act only applies from December 2027.

For firmware teams the engineering consequence is that you must be able to answer "which devices in the field run the affected build?" in hours. That means build provenance, an SBOM and an OTA path that actually works.

Is your release pipeline ready to answer that question tonight?

<b>2. Post: Security wake-up — Your SDK branch can expire</b>
The ESP-IDF v5.2 branch hit end-of-life in August, and the fixes kept coming for newer branches.

The 5.2.8 release shipped NimBLE CVE fixes and tells users to upgrade. Fixes in v5.3.6 touch the HTTP server, protocomm, DHCP server and the JPEG decoder.

The detail I find interesting is that an SDK pin is a security decision, not just a build setting. A device that never updates its toolchain quietly inherits every advisory.

How often do you audit the framework version across your fielded products?

<b>3. Post: Tooling unlock — DMA2D arrives in ESP-IDF</b>
Colour conversion off the CPU is a big deal for small-display firmware.

ESP-IDF v6.0.3 adds an asynchronous DMA2D colour conversion API. It also adds ISP RAW input from memory.

On dual-core FreeRTOS designs driving a UI, every cycle moved to a peripheral is a cycle freed for the BLE stack and the application. I would want to measure the frame-time gain before claiming anything, but the direction is right.

Has anyone profiled this on a real LVGL workload?

<b>5. Post: Integration leap — Wi-Fi Aware on an MCU</b>
Wi-Fi Aware pairing is now an experimental feature in ESP-IDF v6.1.

It lets nearby devices discover each other without an access point. The release notes already list a known issue: pairing fails with some iPhone 17 models, which is the reality of any new interop feature.

The takeaway for me is to treat the experimental label seriously and test against real phones before promising it to anyone.
