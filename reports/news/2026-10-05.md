<b>1. Post: Integration leap — one chip, four radios</b>
Espressif's ESP32-S31 puts Wi-Fi 6, Bluetooth 5.4, Thread/Zigbee and Ethernet on one RISC-V chip.

Until now that mix usually meant two chips and a board respin. It is now reported to be in mass production.

The engineering point is commissioning. BLE can onboard a device while 802.15.4 carries the Matter-over-Thread traffic, with no radio coexistence juggling between separate parts. I will still wait for solid ESP-IDF support before trusting it.

<b>2. Post: Security wake-up — the update path is the attack surface</b>
A bug in the firmware-update code is the most uncomfortable kind.

CVE-2026-10672 is an out-of-bounds read in Zephyr's LwM2M firmware-update component, reachable through crafted CoAP requests. It leaks only 13 bytes, but it sits in the code that exists to protect the device.

The lesson is that OTA parsing code deserves the same fuzzing and review as any network stack.

When did you last fuzz your own update handler?

Only 16 percent of surveyed companies say they align with the EU's RED cybersecurity rules.
