The EU Cyber Resilience Act's first obligations have been live since 11 September 2026: manufacturers must report actively exploited vulnerabilities and severe incidents affecting their products. Why it matters: vulnerability handling, signed updates and secure boot are becoming job requirements in EU embedded roles, which is exactly the market you are aiming at.

<b>1. Post: Regulatory shift — the CRA clock is already running</b>
The CRA is not coming in 2027. Part of it started on 11 September.

Manufacturers must now report actively exploited vulnerabilities and severe incidents in their products. The full regime applies on 11 December 2027.

The engineering consequence: you need to know which third-party libraries sit in every shipped build, because you cannot report or patch what you cannot trace. An SBOM is now an operational tool, not a checkbox.

Could your team name every dependency in a firmware image shipped last year?

<b>2. Post: Security wake-up — removing a secure boot option</b>
Sometimes the fix for a security flaw is deleting the feature.

Current ESP-IDF releases disable ECDSA Secure Boot V2 on ESP32-H2, ESP32-C5 and ESP32-P4, citing a vulnerability in the ECDSA-based flow. Espressif's detailed errata are not yet public as far as I can find.

If a product signs with ECDSA on those chips, the signing scheme is now a lifecycle risk. Choosing it is not a one-time build flag.

Can your devices change their signing scheme in the field?

https://github.com/espressif/esp-idf/releases

<b>3. Post: Tooling unlock — what Zephyr 4.5 changes for drivers</b>
The Zephyr 4.5 draft notes list a LIN driver API and a Clock Monitor API.

Infineon TriCore architecture support is also in the draft, which brings an automotive-grade core family into Zephyr. Application code mainly needs attention for the Video include path and for deprecated Bluetooth and DMIC pieces.

The interesting shift is that the automotive world's buses are reaching a general-purpose RTOS, so the skills carry over between industrial and automotive.

Have you read a Zephyr migration guide before the release, or after?

https://docs.zephyrproject.org/latest/releases/release-notes-4.5.html
